ℹ️ Settings Information

Order Limit Guidelines:

  • ✅ 10-50: Fast performance, good for testing
  • ✅ 50-200: Balanced performance for most stores
  • ✅ 200-500: For stores with many draft orders
  • ✅ 500-1000: Maximum limit for large stores

Note: This only affects how many orders are displayed and available for reminders. It doesn't affect the scheduling system.
